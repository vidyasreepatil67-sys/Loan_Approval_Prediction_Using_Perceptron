# Loan Approval Prediction

This is a Machine Learning project that predicts whether a loan is **Approved** or **Rejected**.

### Algorithm

* Perceptron

### Technologies

* Python
* NumPy
* Scikit-learn

### Output

The model gives the result as:

* Approved
* Rejected

### Purpose

To use applicant details to predict loan approval.
